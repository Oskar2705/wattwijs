        Airco's

        Het verbruik is een schatting: de airco's geven zelf alleen door hoeveel ze per run verbruiken, in stappen van 0,25 kWh. Na een opdracht kan de Smart M-Air-app de airco een minuut lang niet bedienen. De ECO-stand van de afstandsbediening kan via wifi niet worden ingesteld; een opdracht vanuit deze app zet ECO waarschijnlijk uit.
